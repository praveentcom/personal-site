Illustrate is a native generative AI sandbox for macOS, iOS, and iPadOS that lets users experiment with multiple image generation providers in one app. It supports a bring-your-own-API-key model, giving users full control over costs while enabling features like text-to-image generation, batch generation, prompt enhancement, cost monitoring, and iCloud sync across devices.

Built with SwiftUI, the app is available as a one-time purchase on the [App Store](https://apps.apple.com/us/app/illustrate-genai-sandbox/id6654926182) with lifetime updates included.
