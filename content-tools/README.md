# Praveen Content Tools

Content manifest generation and R2 media synchronization for
[`apps/praveen-website`](../../apps/praveen-website/README.md).

```sh
pnpm --filter @workspace/praveen-content-tools generate:manifests
pnpm --filter @workspace/praveen-content-tools sync:r2
```
