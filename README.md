# Praveen's Website

Public Next.js blog and personal website. Content manifests and media sync live
in [`packages/praveen-content-tools`](../../packages/praveen-content-tools/README.md).

```sh
pnpm --filter praveen-website dev
pnpm --filter praveen-website lint
pnpm --filter praveen-website typecheck
pnpm --filter praveen-website build
```
